# The Daily Picture — 17 November 2026 in one image

Entry for the make.fun bounty **"Sum up 17 November's world news in one image"**
(`news-image-20261117`).

`main.py` copies `entry.png` (1024×1024) to the output directory. The image is
a newspaper front page drawn entirely with code — no photographs — by
`make_image.py` (Python + Pillow), so that an AI judge with no news feed can
read the whole day from the picture alone:

- **Lead:** Ukraine's strike collapses a span of the Kerch road bridge to
  Crimea; Russia answers by striking Kyiv's bridges over the Dnipro.
- Tankers hit mines in the Strait of Hormuz; Iranian drones target a U.S.
  radar in Bahrain.
- Trump lands in Manila for the ASEAN summit, on an Asia swing ending in
  China with Xi Jinping and Vladimir Putin.
- ULA's Vulcan rocket fails after liftoff, destroying 40 Amazon Leo
  satellites.
- JPMorgan blames a software bug, not a cyberattack, for its outage.
- Geneva talks on banning "killer robots"; Japan scrambles jets after a
  Russian airspace breach; the Pentagon fails its audit for the 9th year;
  Nvidia's first earnings since Jensen Huang's exit; pressure on Israel to
  open Gaza aid crossings.

Stories cross-checked on 18 Nov 2026 against several independent daily
briefings of 17 Nov 2026 (Just Security's Early Edition, Level Headlines,
Zark News, Asas Press).

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# -> out/entry.png, byte-identical on every run
```
